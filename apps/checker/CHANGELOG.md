# ประวัติการอัปเดต — PoE Price & Trade Checker

> ไฟล์นี้ถูกฝังไว้ในโปรแกรม (หน้า About) และเป็นข้อความในหน้า release ของ GitHub — เขียนที่เดียว
> หัวข้อของแต่ละรุ่นต้องเป็นรูปแบบ `## <เวอร์ชัน> - <วันที่>` (รุ่นใหม่อยู่บนสุด)

## 1.0.0-rc.13 - 2026-10-20

- แก้: กด F5 / F4 ค้าง ไม่รัวอีก — กดค้าง = ทำครั้งเดียว จนกว่าจะปล่อยปุ่ม (เดิมกดค้าง 9 วินาทีทำงาน 37 ครั้งและส่ง Ctrl+Alt+C เข้าเกมทุกครั้ง) กดใหม่หลังปล่อย = ทำงานปกติ เปลี่ยนไอเท็มได้ทันที
- แก้: F5 / F4 ทำงานเฉพาะเมื่อเกม (PoE1 / PoE2) อยู่หน้าสุด ถ้าหน้าต่างอื่นอยู่หน้าสุด (เช่น เบราว์เซอร์หลังเปิดหน้า trade) โปรแกรมไม่ส่งปุ่มใดๆ และบอกใน Status ว่า "กด F5 ในเกม (ตอนนี้หน้าต่างหน้าสุดคือ …)" — หน้าต่างของโปรแกรมเอง (เช่น popup) อยู่หน้าสุดยังทำงานกับเกมที่จำไว้
- ตัดคำว่า "(TypeScript)" ออกจากชื่อโปรแกรม (title bar, Start menu, shortcut, รายการ Apps ของ Windows, About) — โฟลเดอร์ติดตั้ง ที่เก็บค่า และชื่อ exe ไม่เปลี่ยน ค่าที่ตั้งไว้อยู่ครบ
- แก้: ปิด popup / หน้าต่าง F4 แล้วหน้าต่างหลักของโปรแกรมไม่เด้งขึ้นมาทับเกมชั่วขณะ — หน้าต่างรอจนเกมได้โฟกัสกลับจริงก่อนจึงปิด (เดิมปิดทันทีที่สั่งคืนโฟกัส เกิดแข่งกันได้)
- ตารางข้อมูลที่แนบมากับโปรแกรม (ตาราง alias จาก hub และ mod tier) สร้างใหม่จากข้อมูลล่าสุด

## 1.0.0-rc.10 - 2026-10-19

- ตารางคำพ้อง (alias) อ่านจากไฟล์สาธารณะของ hub ที่ {game}/aliases/latest.json (เดิมเป็นไฟล์ internal ที่ไม่มีจริง) ตามสัญญา SPEC 8.12 — ชุดที่แนบมากับโปรแกรมเป็นสำเนาของไฟล์จริงนั้น
- จุดสีแสดงความนิยม: อ่าน stat_aliases และ stat_groups จากไฟล์เดียวกัน — stat ที่ข้อความเหมือนกันหาแถวใน meta ที่ id หลักของกลุ่ม และกลุ่มที่ต่างแค่ตัวพิมพ์ดูทุก member
- ผ่านเคสสัญญาของ hub ครบ 49 เคส (รวม 8 เคสที่ต้อง "ไม่จับคู่") และ "+45 to maximum Energy Shield" ได้ตัว global ไม่ใช่ Local

## 1.0.0-rc.9 - 2026-10-19

- แก้ F5 (ข้อความที่ไม่มีหัวข้อ { Modifier }): บรรทัดคุณสมบัติ เช่น "Evasion Rating: 64", "Block chance: 25%", "Grants Skill: ...", "Map Tier: 14" และคำอธิบายของเจม/สกุลเงินไม่ถูกนับเป็น mod อีก (ข้อความที่มีหัวข้อ อ่านเฉพาะบรรทัดใต้หัวข้ออยู่แล้ว) — ตรวจกับข้อความไอเท็ม PoE2 จริง 27 ชิ้น

## 1.0.0-rc.8 - 2026-10-19

- แก้ F5: บรรทัดป้ายของไอเท็ม (Searing Exarch Item, Eater of Worlds Item, Shaper/Elder/Crusader/Hunter/Redeemer/Warlord Item, Synthesised/Fractured Item, Mirrored, Split ฯลฯ) ไม่ถูกนับเป็น mod และไม่ติดไปกับ mod ก่อนหน้าอีก (เดิมขึ้นเป็นแถวที่ค้นหาไม่ได้) — ช่วงที่มีแต่ป้ายถูกข้ามทั้งช่วง ป้ายที่อยู่ช่วงเดียวกับ mod ถูกตัดทีละบรรทัด และโปรแกรมจำ influence ไว้กับไอเท็ม (ยังไม่ใช้กรองใน trade)
- แก้ F5: บรรทัดคำอธิบายในวงเล็บที่ยาวหลายบรรทัดถูกข้ามทั้งก้อน
- แก้ log: บรรทัด "mod without a stat id" ขึ้นเฉพาะแถวที่หา id ไม่ได้จริงหลังลองทุกทางแล้ว (ไม่ขึ้นตอนลองทั้งก้อนไม่ผ่านแล้วแยกบรรทัดผ่าน)
- F8 (settings): ห้ามตั้ง hotkey ของโปรแกรมให้ชนกับปุ่มที่โปรแกรมกดเองตอน F5 เพื่อให้เกมคัดลอกไอเท็ม — PoE1 Ctrl+C, PoE2 Ctrl + ปุ่ม "show advanced item descriptions" ที่อ่านจากไฟล์ตั้งค่าของเกม (poe2_production_Config.ini, ค่าเริ่มต้น Alt → Ctrl+Alt+C) — บอกเหตุผลข้างช่องและแสดงรายการปุ่มเหล่านี้ในหน้า settings (อ่านใหม่ทุกครั้งที่เปิด F8)

## 1.0.0-rc.6 - 2026-10-19

- แก้ F5: บรรทัดคำอธิบายในวงเล็บทั้งบรรทัด เช่น "(Attributes are Strength, Dexterity, and Intelligence)" ไม่ถูกนับเป็น mod อีกต่อไป (เดิมขึ้นเป็นแถวที่ค้นหาไม่ได้)
- แก้ F5: ตัด " — Unscalable Value" ท้ายบรรทัดก่อนหา stat id
- แก้ F5: mod หลายบรรทัดใต้หัวข้อ { Modifier } เดียวกัน (เช่น Trigger a Socketed Spell … + Spells Triggered this way have 150% more Cost) จับคู่ทั้งก้อนก่อนแบบเดียวกับ hub แล้วแสดงเป็นแถวเดียว ถ้าทั้งก้อนไม่มี id จึงหาทีละบรรทัด
- ก่อนส่ง Ctrl+C ไปที่เกมทุกครั้ง โปรแกรมปล่อย Shift และ Alt ก่อน เพื่อให้เกมไม่เห็น Alt ค้าง (PoE1 ใส่บรรทัดคำอธิบายเฉพาะตอนมี Alt) และบันทึกสถานะปุ่มก่อน/หลังพร้อมบรรทัดแรกของข้อความที่ได้ใน log.txt
- แก้ log: ปิด popup ด้วยปุ่ม X ไม่ขึ้นคำเตือนว่า "ถูกปิดโดยสิ่งอื่น" อีก และคืนโฟกัสให้เกมเหมือนตอนกด Esc
- แก้ log การอัปเดต: ถ้ายังไม่มี release บน GitHub ขึ้นเป็นข้อความเดียวระดับ info ไม่มี stack และไม่ซ้ำ

## 1.0.0-rc.4 - 2026-10-19

- แก้การหา stat id ของ mod (ใช้ใน F5 trade และจุดสีแสดงความนิยม): เลิกเดาด้วยความคล้ายของข้อความ (เดิมเดาผิดเกือบทุกครั้งที่เดา เช่น "reduced Duration" ไปเป็น Spark Duration) ใช้กติกาเดียวกับ hub ตรงตามข้อความเท่านั้น
- mod ที่หา stat id ไม่ได้: ติ๊กค้นหาไม่ได้ ไม่อยู่ใน URL trade และคอลัมน์จุดสีขึ้น "?" (ไม่มีข้อมูล) แยกจาก mod ที่มีข้อมูลแต่ไม่ติดอันดับ
- ตัดช่วงค่า "(25-35)" และป้ายท้ายบรรทัด (crafted) (implicit) ออกก่อนหา stat id
- มีตาราง alias จาก hub แนบมากับโปรแกรม และโหลดของใหม่จาก hub เมื่อมี (ออฟไลน์ใช้ของเดิม ไม่ crash)
