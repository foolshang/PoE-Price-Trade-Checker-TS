# ประวัติการอัปเดต — PoE Price & Trade Checker (TypeScript)

> ไฟล์นี้ถูกฝังไว้ในโปรแกรม (หน้า About) และเป็นข้อความในหน้า release ของ GitHub — เขียนที่เดียว
> หัวข้อของแต่ละรุ่นต้องเป็นรูปแบบ `## <เวอร์ชัน> - <วันที่>` (รุ่นใหม่อยู่บนสุด)

## 1.0.0-rc.4 - 2026-10-19

- แก้การหา stat id ของ mod (ใช้ใน F5 trade และจุดสีแสดงความนิยม): เลิกเดาด้วยความคล้ายของข้อความ (เดิมเดาผิดเกือบทุกครั้งที่เดา เช่น "reduced Duration" ไปเป็น Spark Duration) ใช้กติกาเดียวกับ hub ตรงตามข้อความเท่านั้น
- mod ที่หา stat id ไม่ได้: ติ๊กค้นหาไม่ได้ ไม่อยู่ใน URL trade และคอลัมน์จุดสีขึ้น "?" (ไม่มีข้อมูล) แยกจาก mod ที่มีข้อมูลแต่ไม่ติดอันดับ
- ตัดช่วงค่า "(25-35)" และป้ายท้ายบรรทัด (crafted) (implicit) ออกก่อนหา stat id
- มีตาราง alias จาก hub แนบมากับโปรแกรม และโหลดของใหม่จาก hub เมื่อมี (ออฟไลน์ใช้ของเดิม ไม่ crash)
