## 1.0.0-beta.15 - 2026-10-18

- **ระบบอัปเดตใหม่:** เช็ครุ่นใหม่ตอนเปิดโปรแกรมและทุก 24 ชั่วโมง เจอรุ่นใหม่จะมีปุ่ม "อัปเดตเลย" (ติดตั้งแล้วเปิดโปรแกรมใหม่) หรือ "อัปเดตตอนปิดโปรแกรม" (ยกเลิกได้) ไม่มีอะไรติดตั้งเองถ้าไม่ได้เลือก
- ตัวเลือก "อัปเดตอัตโนมัติ" ใน F8 (เปิด = โหลดรุ่นใหม่รอไว้เบื้องหลัง, ปิด = แจ้งอย่างเดียวและมีปุ่ม "เช็คอัปเดต")
- จุดแดงแบบ Discord ที่ไอคอน taskbar และ tray เมื่อมีเรื่องใหม่ (รุ่นใหม่ / NeverSink) กดเปิดโปรแกรมแล้วจะมีหน้ารายละเอียดทุกเรื่องที่ค้าง
- ปุ่ม About: เวอร์ชัน ประวัติการอัปเดต และลิงก์ GitHub
- แบบ zip: อัปเดตเองไม่ได้ ปุ่มอัปเดตจะเปิดหน้าดาวน์โหลดแทน
