# Release drafts (archive)

These files are the **drafts written before v1.0.0** (README, CHANGELOGs, the old repository's release guard, the question about where the Checker is released).
They were used for the v1.0.0 release and are kept for the record only: the live versions are `release/README_public.md`, `apps/*/CHANGELOG.md`, and the
decisions in docs/PLAN.md section F and docs/PHASE5.md (Addendum 3 and 11). Some of the text is outdated (for example `B0-where-does-the-checker-go.md` still shows
the option table that recommends one release for both programs; Winai chose option 2, a repository of its own for the Checker).
