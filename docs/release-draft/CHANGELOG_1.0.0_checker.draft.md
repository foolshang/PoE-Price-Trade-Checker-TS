## 1.0.0 - <วันที่ปล่อย>

รุ่นแรกที่ปล่อยจริงของ PoE Price & Trade Checker (เขียนใหม่ด้วย Electron แทนโปรแกรม Python เดิม — ใช้ได้ทั้ง PoE 1 และ PoE 2)

- **F5 — ค้นหา trade จากไอเท็มใต้เมาส์:** ชี้ไอเท็มในเกมแล้วกด F5 โปรแกรมให้เกมคัดลอกไอเท็ม (PoE 2 ใช้ปุ่ม "show advanced item descriptions" ของคุณจากไฟล์ตั้งค่าเกม) แล้วเปิดหน้า trade ให้
  ไอเท็ม Rare / Magic มีหน้าต่างเลือก mod: ติ๊ก mod ที่จะค้นหา ใส่ min / max, ดู tier ของแต่ละ mod, เครื่องหมายราคา, ลูกศร roll สูง/ต่ำ และจุดสีบอกว่า mod นั้นนิยมแค่ไหนในตำแหน่งนั้น (ข้อมูลจาก hub)
- **หา stat id ของ mod แบบไม่เดา:** จับคู่ตามข้อความตรงๆ ด้วยกติกาเดียวกับ hub (รวมตารางคำพ้องจาก RePoE) mod ที่หาไม่ได้จริงขึ้น "?" ติ๊กค้นหาไม่ได้ ไม่ถูกใส่ในการค้นหา — ไม่มีการเดาให้ผิด ตรวจกับไอเท็มจริงของทั้งสองเกม
- **F4 — ตารางอ้างอิง mod ของ skill:** พิมพ์ชื่อ skill ดูว่า mod / passive ไหนนิยมในแต่ละช่วงและ slot
- **สลับ PoE 1 / PoE 2 เองตามเกมที่อยู่หน้าสุด** และเลือก league ให้อัตโนมัติ (ปิดได้ใน F8)
- **F5 / F4 ทำงานเฉพาะตอนเกมอยู่หน้าสุด** — หน้าต่างอื่น (เช่น เบราว์เซอร์) ไม่ถูกส่งปุ่มอะไรเลย กดค้างไม่รัว (กดค้าง = ทำครั้งเดียว)
- **F8 — Settings:** เลือกเกม, ตั้งปุ่มลัด (ห้ามตั้งซ้ำกัน ห้ามชนปุ่มของเกม และห้ามชนปุ่มที่โปรแกรมกดเองตอนสั่งให้เกมคัดลอก), เปิด/ปิดการอัปเดตอัตโนมัติ, ปุ่ม X ลง tray หรือปิดจริง
- **หน้า Filter Generator ในตัว** (สร้าง loot filter แบบ NeverSink / Whitelist) และ **นำเข้าค่าจากโปรแกรม Python รุ่นเก่า** ให้ครั้งเดียว (ไม่แก้ไฟล์เดิม)
- **แจ้งเตือน NeverSink รุ่นใหม่** ทับจอเกมและที่ไอคอน (จุดแดงแบบ Discord) แล้วสร้าง filter ใหม่ให้เมื่อเปิดตัวเลือกไว้
- **อัปเดตตัวเองได้ (แบบติดตั้ง):** เช็คตอนเปิดและทุก 24 ชั่วโมง ไม่ปิดโปรแกรมหรือติดตั้งโดยที่คุณไม่ได้เลือก · แบบ zip (ไม่ต้องติดตั้ง) อัปเดตเองไม่ได้ จะแจ้งและเปิดหน้าดาวน์โหลดให้
- ปุ่ม **About:** เวอร์ชัน ประวัติการอัปเดต และลิงก์ GitHub
- ไม่ต้องใช้สิทธิ์ admin · ค่าที่ตั้งเก็บใน `%LOCALAPPDATA%\PoePriceTradeTS` ถอนการติดตั้งไม่ลบค่า
