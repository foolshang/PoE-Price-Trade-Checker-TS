## 1.0.0 - <วันที่ปล่อย>

รุ่นแรกที่ปล่อยจริงของ PoE1 & PoE2 Filter Generator บน Electron (แทนโปรแกรม Python เดิม — ผลลัพธ์ filter เหมือนเดิม)

- **สร้าง loot filter ได้ 2 แบบในหน้าต่างเดียว** ทั้ง PoE1 และ PoE2: **NeverSink** (ใช้ tier ของ NeverSink ตรงๆ เลือก Strictness 0–6 ตั้งเสียงแจ้งเตือนเองได้ 6 ช่อง) และ **Whitelist** (โชว์เฉพาะที่คุณเลือกเป็น tier S / A / B / C ที่เหลือซ่อน ปรับสไตล์ เสียง จำนวนขั้นต่ำได้ทีละชิ้นหรือทีละหมวด)
- **ติดตั้งคลิกเดียว** (ไม่ถามสิทธิ์ admin) หรือ **zip แตกแล้วรัน** — ค่าที่ตั้งเก็บใน `%LOCALAPPDATA%\PoeFilterGenTS` ไม่เขียนอะไรในโฟลเดอร์ที่แตก zip
- **อัปเดตตัวเองได้ (แบบติดตั้ง):** เช็ค 20 วินาทีหลังเปิดและทุก 6 ชั่วโมง โหลดเบื้องหลัง แจ้งที่แถบด้านบน ติดตั้งตอนปิดโปรแกรม หรือกด "รีสตาร์ทเพื่ออัปเดต" เอง (ไม่ปิดโปรแกรมให้เองระหว่างใช้งาน) · แบบ zip อัปเดตเองไม่ได้ จะแจ้งและเปิดหน้าดาวน์โหลดให้
- **ปุ่ม X ลง tray** (เปลี่ยนให้ปิดจริงได้ที่ About), **About:** เวอร์ชัน ประวัติการอัปเดต ลิงก์ GitHub
- **เปิด filter เก่ามาแก้** (ไฟล์ที่แท็บ Whitelist สร้างไว้) และ **นำเข้าค่าจากโปรแกรม Python รุ่นเก่า** ให้ครั้งเดียว (ไม่แก้ไฟล์เดิม)
- **regenerate อัตโนมัติ** เมื่อ NeverSink ออกเวอร์ชันใหม่ (ติ๊กตัวเลือกไว้ — เช็คตอนเปิดโปรแกรม) หรือกด **Refresh NeverSink Base** เอง
- ใช้บนเว็บได้ด้วย (ฟังก์ชันเดียวกัน)
